# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-17

### Added
- `SKILL.md` entry point with mandatory workflow, design, responsive, engineering, accessibility, and seven-part audit rules.
- `references/`: design philosophy, creative direction, visual quality, typography, spacing and layout, responsive design, frontend engineering, software architecture, clean code, logical thinking, accessibility, performance, security, and quality assurance.
- `checklists/`: design review, responsive review, code review, accessibility review, and final audit with report template.
- `examples/`: good design decisions, bad design patterns, and engineering examples.
- Project documentation: README, LICENSE (MIT), CONTRIBUTING, and this changelog.
